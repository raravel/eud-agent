      Safety

      AI hands on your map, without breaking it

      A broken map file is hard to recover. So every write checks its conditions first, and a failure puts things back the way they were.

      A git commit per turn

      The app keeps your project folder in git and commits after every agent request. Pick any commit in the history to revert it.

      Candidate maps, verified Apply

      Terrain and unit changes build up on a candidate map first. Apply takes a full backup, checks free space, verifies the change stays in scope and swaps the file atomically; a failed check restores the backup.

      Only the areas you allow

      The verifier rejects a candidate that touches anything outside the request's selected area and layers. Map properties (slots, forces) change only in their own dialog.

      DAT stores only what changed

      Unit, weapon and upgrade values are saved as {before, after} overrides. If before no longer matches the stock value, the build refuses, so nothing is silently overwritten.

      Plays nice with SCMDraft

      While SCMDraft holds the map open, writes stop and the app asks you to save and close it. Changes saved from outside are picked up by the open map session.

      The build decides

      Success means euddraft wrote a fresh output map. Tracebacks are folded to the innermost line of your project, and the full log stays in build/euddraft/build.log.

      Install

      Download and run it; the first screen walks you through the rest.

      1. 1

        Get the installer

        Download the -setup.exe installer. It installs per user, so no administrator rights are needed.

        The installer is not code-signed, so SmartScreen may warn you. Click More info → Run anyway.

      2. 2

        Pick a project

        Open an existing .eap, start from an SCX/SCM or the new map wizard, or import an E3S.

      3. 3

        Set up euddraft and reference docs

        The latest euddraft is downloaded and checksum-verified automatically, or point it at your own euddraft folder. The embedding model and doc index (about 600 MB) download once.

      4. 4

        Connect an AI provider

        Sign in to at least one of the six providers and start asking.

      Windows 10/11 64-bit · WebView2 runtime (preinstalled on most systems)

      1. 1

        Get the DMG

        Download the Apple Silicon DMG and move the app into Applications. Intel Macs are not supported.

        The first screen guides you in the same order as on Windows.

      The macOS build works, but testing is done on Windows and auto-update is Windows-only for now. Windows-only features such as Open in SCMDraft 2 fall back to an alternative.

      FAQ

      Is the app available in English?

      Yes. The interface is in English and Korean and follows your system language; change it any time in Settings → Language. The agent answers in the language you choose. The built-in reference docs come mostly from the Korean EUD community, so some search results are in Korean.

      Do I need EUD Editor 3?

      No. Builds use euddraft only. Importing an old .e3s project or exporting to E3S never launches EUD Editor either; the app reads and writes the file format itself.

      Do I need StarCraft installed?

      Map rendering, the new map wizard and DAT wiki pictures read tilesets and GRPs straight from your StarCraft install. If the install isn't found, set it in Settings → Compile; until then those views show text only.

      What if I don't like what the agent changed?

      Code and DAT changes are reverted by reverting their commit in the history. Terrain and unit changes live only on the candidate map until Apply, so you just discard them; after Apply, Undo in the Map window restores the original bytes from its backup.

      Does it check that the map works in game?

      The app verifies the build. How it plays still needs a human in the game. The built map is copied straight into StarCraft's Maps/eud-agent/ folder, so you can test it right away.

      Does it cost anything?

      The app is free. AI usage follows the plan of the provider you connect. With Ollama you can run on a local model.
