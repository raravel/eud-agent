동작 데모

    실제 앱 화면을 단순화한 목업입니다. 반짝이는 버튼은 직접 눌러 볼 수 있습니다.

    EUD Editor 없이

    프로젝트는 텍스트 파일입니다

    project.eap, src/**/*.eps, 바뀐 값만 담는 dat/*.json. EDS와 플러그인은 빌드할 때마다 새로 생성됩니다.

    추측 대신 확인

    빌드 결과로 판단합니다

    에이전트는 수정 후 직접 euddraft를 돌리고, 오류가 나면 파일·줄 단위 진단을 보고 고칩니다. 출력 맵은 스타크래프트 Maps 폴더에도 복사됩니다.

    언제든 되돌리기

    모든 턴이 기록됩니다

    요청 하나가 커밋 하나. 지형 변경은 전체 백업과 검증을 거쳐 적용되고, 맵 창에서 정확히 이전 바이트로 되돌립니다.

    구조

    요청 하나가 맵이 되기까지

    흐름을 고르면 데이터가 지나가는 경로가 켜집니다. 각 상자를 누르면 그 부분이 하는 일을 볼 수 있습니다.

    구성 요소

    상자를 선택하세요

    왼쪽 도식의 상자를 누르거나 흐름 버튼을 누르면 설명이 여기에 표시됩니다.

      안전장치

      AI가 만지되, 망가뜨리지 않게

      맵 파일은 한 번 깨지면 복구하기 어렵습니다. 그래서 쓰기마다 조건을 확인하고, 실패하면 원래 상태로 돌려놓습니다.

      턴마다 git 커밋

      앱이 프로젝트 폴더를 git으로 관리하고, 에이전트의 요청 하나가 끝날 때마다 커밋합니다. 변경 기록에서 커밋 하나를 골라 되돌릴 수 있습니다.

      후보 맵과 검증된 Apply

      지형·유닛 변경은 먼저 후보 맵에 쌓입니다. Apply할 때 전체 백업, 여유 공간 확인, 변경 범위 검증을 거쳐 원자적으로 교체하고, 검증이 실패하면 백업을 복원합니다.

      허락된 영역만 수정

      요청에 붙은 선택 영역과 레이어 밖을 건드리는 후보는 검증기가 거부합니다. 맵 속성(슬롯·포스)은 전용 대화상자에서만 바뀝니다.

      DAT는 바뀐 값만

      유닛·무기·업그레이드 값은 {before, after} 오버라이드로만 저장합니다. before가 원본 값과 다르면 빌드가 거부해서, 엉뚱한 값을 덮어쓰지 않습니다.

      SCMDraft와 충돌 방지

      SCMDraft가 맵을 잡고 있으면 쓰기를 멈추고 “저장 후 닫아 주세요”라고 안내합니다. 외부에서 저장한 변경은 열린 맵 세션이 따라갑니다.

      빌드가 최종 판정

      euddraft가 새 출력 맵을 만들어야 성공입니다. 트레이스백은 가장 안쪽 프로젝트 줄로 모아서 보여 주고, 전체 로그는 build/euddraft/build.log에 남깁니다.

      그 밖에

      맵 제작에 필요한 도구가 한 곳에

      새 맵 마법사

      타일셋, 크기, 지형 브러시, 12개 슬롯과 4개 포스를 고르고 미리보기까지 확인한 뒤 빈 맵을 만듭니다.

      참고 문서 검색

      EUD 커뮤니티 문서를 앱 안에서 검색합니다. 에이전트도 같은 인덱스로 근거를 찾습니다.

      사운드 가져오기

      오디오를 첨부하면 FFmpeg로 자르고 변환해 맵에 WAV로 등록합니다. 한 번에 128개까지.

      @ 멘션

      입력창에 @를 치면 맵의 영역·로케이션과 프로젝트 파일을 찾아 요청에 붙일 수 있습니다.

      맵 이미지 내보내기

      지형, 두다드, 유닛까지 그린 전체 맵 그림을 PNG로 저장하거나 클립보드에 복사합니다.

      E3S 가져오기·내보내기

      EUD Editor 3 프로젝트를 가져와 Native 프로젝트로 바꾸고, 필요하면 다시 E3S로 내보냅니다.

      Python 플러그인

      src/**/*.py 진입점과 고정된 PyPI 의존성을 매니페스트에 기록하고 빌드마다 같은 환경으로 실행합니다.

      여러 세션 동시에

      세션마다 대화가 따로 있고, 동시에 돌려도 프로젝트 쓰기는 한 번에 하나씩 처리됩니다.

      AI 제공자

      이미 쓰는 AI로 연결하세요

      각 제공자의 공식 로그인과 세션을 그대로 씁니다. 로컬 모델이 필요하면 Ollama를 연결할 수 있습니다.

      설치 방법

      내려받아 실행하면 첫 화면이 나머지 준비를 안내합니다.

      1. 1

        설치 파일 받기

        -setup.exe 설치 프로그램을 받습니다. 사용자 단위 설치라 관리자 권한이 필요 없습니다.

        코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다. 추가 정보 → 실행을 누르세요.

      2. 2

        프로젝트 선택

        기존 .eap를 열거나, SCX/SCM 또는 새 맵 마법사로 만들거나, E3S를 가져옵니다.

      3. 3

        euddraft와 참고 문서 준비

        최신 euddraft를 자동으로 받아 체크섬을 확인합니다. 기존 euddraft 폴더를 지정해도 됩니다. 임베딩 모델과 문서 인덱스(약 600MB)는 처음 한 번만 받습니다.

      4. 4

        AI 제공자 연결

        다섯 제공자 중 하나 이상에 로그인하면 바로 요청할 수 있습니다.

      Windows 10/11 64-bit · WebView2 런타임(대부분 기본 설치됨)

      1. 1

        DMG 받기

        Apple Silicon용 DMG를 받아 앱을 응용 프로그램 폴더로 옮깁니다. Intel 맥은 지원하지 않습니다.

      2. 2

        처음 실행 허용

        Apple 개발자 서명이 없어 Gatekeeper가 막습니다. 앱을 우클릭 → 열기를 선택하거나 아래 명령을 실행하세요.

        xattr -dr com.apple.quarantine /Applications/eud-agent.app
      3. 3

        프로젝트·euddraft·제공자 준비

        Windows와 같은 순서로 첫 화면이 안내합니다.

      macOS 빌드는 동작하지만 검증은 Windows 기준이고, 자동 업데이트는 아직 Windows에서만 동작합니다. SCMDraft 2로 열기처럼 Windows 전용인 기능은 대체 동작을 합니다.

      자주 묻는 질문

      EUD Editor 3가 꼭 있어야 하나요?

      아니요. 빌드에는 euddraft만 씁니다. 예전 .e3s 프로젝트를 가져오거나 E3S로 내보낼 때도 EUD Editor를 실행하지 않고, 파일 형식을 직접 읽고 씁니다.

      스타크래프트가 설치되어 있어야 하나요?

      맵 렌더링, 새 맵 마법사, DAT 위키의 그림은 설치된 스타크래프트에서 타일셋과 GRP를 직접 읽습니다. 설치 경로를 찾지 못하면 설정 → 컴파일에서 지정할 수 있고, 그 전까지 해당 화면은 텍스트만 보여 줍니다.

      에이전트가 만든 변경이 마음에 안 들면요?

      코드와 DAT 변경은 변경 기록에서 해당 커밋을 되돌립니다. 지형·유닛 변경은 Apply 전에는 후보 맵에만 있어서 버리면 끝이고, Apply한 뒤에는 맵 창의 Undo가 백업해 둔 원본 바이트로 되돌립니다.

      게임에서 제대로 동작하는지도 확인해 주나요?

      빌드 성공까지는 앱이 확인합니다. 실제 플레이 동작은 사람이 게임에서 확인해야 합니다. 빌드된 맵은 스타크래프트의 Maps/eud-agent/ 폴더에 바로 복사되니 곧장 테스트할 수 있습니다.

      비용이 드나요?

      앱은 무료입니다. AI 사용량은 연결한 제공자의 요금제를 따릅니다. Ollama를 쓰면 로컬 모델로 돌릴 수 있습니다.
