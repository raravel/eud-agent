Native EUD 맵 AI 저작 도구

자연어로 epScript를 작성하고
Native 프로젝트에 안전하게 적용하세요

eud-agent는 StarCraft EUD 맵 제작을 위한 Native 데스크톱 AI 저작 도구입니다. epScript와 DAT 변경을 검토한 뒤 euddraft로 결과 맵을 직접 빌드합니다.

Windows 10/11 (64-bit) · 무료 · 자동 업데이트

시작하기 전에

설치 전 아래 항목을 확인하세요.

Windows 10/11

64-bit 데스크톱 환경에서 동작합니다.

WebView2 런타임

보통 Windows에 기본 포함됩니다. 없을 경우 여기서 설치하세요.

euddraft

최초 설정에서 최신 버전을 자동 다운로드합니다. 기존 euddraft 폴더·파일을 지정해도 됩니다. EUD Editor는 필요하지 않습니다.

Codex

설정 화면에서 Codex를 설치하거나 기존 로그인으로 연결할 수 있습니다.

최초 실행 시 임베딩 모델(bge-m3)과 RAG 인덱스를 자동으로 내려받습니다(1회, 약 600MB 이상). 다운로드가 끝나면 이후 실행은 즉시 시작됩니다.

설치 방법

네 단계면 끝납니다.

  1. 1

    설치 파일 다운로드

    위의 Windows용 다운로드 버튼으로 최신 -setup.exe 설치 프로그램을 받습니다.

  2. 2

    설치 프로그램 실행

    내려받은 파일을 실행합니다. 사용자 단위(현재 사용자) 설치라 관리자 권한이 필요 없습니다.

    코드 서명이 적용되지 않아 Windows SmartScreen 경고가 나타날 수 있습니다. 추가 정보 → 실행을 눌러 진행하세요.

  3. 3

    Native 프로젝트와 euddraft

    기존 프로젝트를 열거나 SCX에서 만들거나 E3S를 가져온 뒤 최신 euddraft를 자동 설치합니다. 기존 폴더·파일도 지정할 수 있으며, 이어서 검증된 RAG 자산을 준비합니다.

  4. 4

    Codex 로그인과 빌드

    Codex 로그인을 마치면 자연어 지시, changeset 검토, 직접 euddraft 빌드를 사용할 수 있습니다.

자동 업데이트

설치 후에는 앱이 서명된 업데이트를 자동으로 확인하고 적용합니다. 내려받은 모델과 설정은 업데이트 시에도 그대로 보존됩니다.
