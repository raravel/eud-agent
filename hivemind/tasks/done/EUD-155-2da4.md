## Description
Introduce the v2 on-disk index format in `rag.rs`: add `tier_level: u8` to `IndexEntry`, write it
after the vector and before the text field, bump `INDEX_VERSION` to 2 (MAGIC "ERAG" unchanged), and
make `load_index` read v2 and reject v1. The format is mirrored in `ci/build_rag_index.rs` (T3) — a
differential test must prove the two serializers produce byte-identical output for the same entries.
