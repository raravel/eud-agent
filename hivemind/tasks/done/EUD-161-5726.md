## Description
SEPARATE, GATED track — not on the L1/L2 critical path, not wired into CI. A local-only differential
test embeds a fixed corpus subset on the CPU EP and (if available) the GPU/CUDA EP, recording pairwise
cosine into a fixture. The acceptance gate: GPU-built vectors are adoptable for the CPU-query runtime
ONLY if pairwise cosine is effectively 1.0 (> 0.9999). If the gate fails, the documented conclusion is
GPU build not adopted and CPU build remains canonical. Enabling CUDA needs the ort `cuda` feature on
the `ci` builder and must not alter the canonical CPU path.
