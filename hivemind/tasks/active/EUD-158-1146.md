## Description
Add a `ci` migration binary (`migrate_rag_index.rs`) that upgrades the published v1 `rag-index.bin`
to v2 WITHOUT re-embedding: read v1 vectors+text+source, re-parse `ci/corpus/*.jsonl` to derive each
chunk id (`fnv1a64(chunk_key)`) and `tier_level` (no embedding), join on id, and write v2. Vectors
are copied byte-for-byte. Migration is all-or-nothing: any unmatched id (either side) is a hard error.
